# Sakshi's Scoop & Swirl Cafe

A tiny JavaScript ice-cream cafe app created for Git/GitLab practical practice.

## Setup

Requires Node.js. No external packages are needed.

```bash
node test.js
node check.js
```

## App features

- Ice-cream menu and prices
- Percentage discount codes
- Tax calculation
- Receipt formatting
- Simulated checkout

## Practice rules

- Use Conventional Commits: `feat:`, `fix:`, `docs:`, `chore:`, `revert:`.
- One logical change per commit.
- Never commit real secrets, logs, or `node_modules/`.
- Never force-push to `main`.
- When rewriting your own feature branch, prefer `git push --force-with-lease`.
